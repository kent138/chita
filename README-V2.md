# Матрёшка 2.0 — отдельная тестовая версия

**Публичная ссылка:** https://matreshka-v2.vercel.app/  
**Исходный магазин (не изменялся):** https://matreshkachita.vercel.app/  
**Ветка:** `matreshka-v2` (ветка `master` не изменена)  
**Vercel project:** `matreshka-v2`.

## Что перенесено

43 товара с исходного сайта, включая их названия, описания, состав, цены, остатки, категории, идентификаторы и фотографии. Товары перенесены в отдельное хранилище Vercel Blob. Изображения преобразованы из Base64 в отдельные файлы WebP, и ссылки на них сохранены в новом каталоге.

Каталог хранится в отдельном Blob `v2/catalog.json`; старый Turso не используется и не изменяется. Исходный публичный каталог был скопирован в резервный Blob `v2/backup/original-public-catalog.json`.

## Быстродействие

В старой версии `GET /api/products` возвращал примерно 11.4 МБ (фотографии включены в JSON). В новой версии список всех товаров составляет около 39 КБ, а первая страница из 24 товаров — около 26 КБ. Новая версия загружает страницы по 24 товара и отдельно получает фильтры; фотографии отдаются отдельными файлами CDN.

## Доступ и ограничения

- Временная тестовая версия: **оформление заказов и личные кабинеты отключены**, чтобы избежать любых изменений в основном магазине.
- Административная панель нового сайта сохраняет товары в отдельный каталог. Пароль берётся из переменной окружения `ADMIN_PASSWORD` в проекте Vercel; не храните его в GitHub.
- Перед запуском продаж нужен отдельный защищённый бэкенд заказов, пользователей и платежей, а также ротация административных паролей.
- Временные маршруты импорта удалены, переменная `V2_IMPORT_ENABLED` выключена.
- Vercel Blob подходит для текущего демонстрационного каталога и теста на 500 элементов, но для большого числа одновременных редактирований и транзакций нужна отдельная БД.

## Проверки

```bash
npm install
npm test
```

Покрытие: каталог из 500 **синтетических** товаров, пагинация 24 товара, кириллический поиск, фильтры, получение карточки и блокировка заказов в тестовой версии. Для настоящих 500 товаров все фотографии и нагрузку нужно проверить отдельно.

## Развертывание

Проект `matreshka-v2` использует `server-v2.js` и ветку `matreshka-v2` репозитория `kent138/chita`. Переменные окружения в настройках Vercel:

- `BLOB_READ_WRITE_TOKEN` — токен отдельного хранилища V2.
- `ADMIN_PASSWORD` — пароль админ-панели тестового сайта.
- `V2_IMPORT_ENABLED=0` — временный импорт отключён.

Никогда не подключайте к этой тестовой версии переменные `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN` исходного магазина без отдельного согласованного плана миграции.
