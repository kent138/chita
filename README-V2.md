# Матрёшка 2.1

**Сайт:** https://matreshka-v2.vercel.app/  
**Исходный магазин:** https://matreshkachita.vercel.app/ (не изменён)  
**Ветка:** `matreshka-v2` — отдельна от `master`.

В новой версии есть быстрый каталог с 43 исходными товарами и фотографиями, отдельный сервер для полноценного интернет-магазина, PostgreSQL, регистрация, корзина, история заказов, администрирование товаров и заказов, отзывы с модерацией, безопасное списание остатков и защита от дублирования заказов.

**Статус:** программная часть протестирована на локальной PostgreSQL, включая 500 тестовых товаров и параллельные заказы. Публичный адрес продолжает работать как каталог, а заказ и регистрация заблокированы до подключения отдельной базы данных и настройки правовых и коммерческих данных продавца. Это сделано намеренно, чтобы не принимать реальные заказы в неподготовленном магазине.

Подробные инструкции и переменные окружения: **[STORE-LAUNCH.md](./STORE-LAUNCH.md)**.

```bash
npm install
npm test
```

Для запуска полного интеграционного теста используется локальная тестовая база PostgreSQL через `TEST_DATABASE_URL`. Встроенный каталог не читает и не изменяет старую базу Turso.
