# Матрёшка 2.0 — независимый тестовый каталог

Сайт: https://matreshka-v2.vercel.app/  
Основной магазин (не изменяется): https://matreshkachita.vercel.app/

Эта ветка `matreshka-v2` запускает **отдельный проект Vercel** и использует **отдельное хранилище Vercel Blob**. Производственная база Turso основного магазина не подключена к V2.

## Что перенесено
- 43 реальных товара и 43 фотографии, перенесённые 11.11.2026 из публичного каталога основного магазина.
- Идентификаторы, названия, цены, описания, состав, материал, ширина, категории, остатки и признак популярных товаров.
- Товары загружаются по 24 за раз, фильтры запрашиваются параллельно.
- Фото хранятся как отдельные WebP-файлы, а не как Base64 внутри ответов API.

**Важно:** Это тестовый каталог для проверки скорости и ассортимента. Регистрация, история заказов, корзина и оформление заказов в V2 отключены; покупки можно делать на основном сайте. Старые заказы и аккаунты не копировались. Не используйте V2 для реальных продаж, пока не создана отдельная транзакционная база данных и не пройдены тесты оформления.

## Работа с данными
- Данные каталога: Vercel Blob `v2/catalog.json`.
- Изображения: Vercel Blob `v2/media/`.
- Переменные окружения в отдельном проекте Vercel: `BLOB_READ_WRITE_TOKEN` и `ADMIN_PASSWORD`.
- `ADMIN_PASSWORD` **никогда не хранить в GitHub**.
- Администратор может в тестовой версии создавать, менять и удалять товары. Доступ — меню «⋯» → «Редактировать каталог».
- При изменениях в Blob возможна задержка обновления CDN до 60 секунд. Для полноценной многопользовательской админ-панели вместо одного JSON нужен SQL/транзакционное хранилище.

## Запуск локально
1. Установите Node.js 24.x, затем `npm install`.
2. Создайте локальный файл `.env` или экспортируйте `BLOB_READ_WRITE_TOKEN` и `ADMIN_PASSWORD` из вашего **отдельного** проекта Vercel.
3. `npm start` — сервер на http://localhost:3000.

## Основные маршруты
- `GET /api/v2/status`: количество товаров и фотографий.
- `GET /api/products?limit=24&page=1`: постраничная выдача.
- `GET /api/products/facets`: доступные фильтры.
- `GET /api/products/:slug`: карточка товара.
- `POST /api/admin/verify`: проверка авторизации администратора.
- `POST /api/admin/products`, `PUT/DELETE /api/admin/products/:id`: управление каталогом.

## Производительность и масштаб
Список из первых 24 товаров на момент проверки выдавался в JSON около 40 КБ вместо 11,4 МБ исходного каталога с фотографиями. Архитектура пагинации рассчитана на 500+ товаров, но нагрузочные тесты при 500 товарах ещё не проводились.

## Файлы
- `server-v2.js` — автономный Express-сервер V2.
- `v2-api.js` — API каталога и админ-панели.
- `public/js/app.js` — SPA и быстрый каталог.
- `public/css/style.css` — стили.
- `vercel.json` — отдельный деплой V2.

Старые файлы `server.js` и `database.js` сохранены для сравнения, но **не используются** V2.
