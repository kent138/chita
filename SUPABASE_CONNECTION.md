## Один необходимый шаг по настройке секретного подключения

Пароль базы не следует передавать в чат, GitHub или общие документы. Задайте его самостоятельно в интерфейсе Supabase и сохраните **только** в защищённой переменной Vercel.

1. Откройте https://supabase.com/dashboard/project/odaitemhtecieklsbnpd/sql/new
2. Выберите уникальный случайный пароль для базы минимум из 32 латинских букв и цифр. Это **отдельный пароль**, не пароль админа.
3. Выполните SQL, подставив ваш пароль:

```sql
ALTER ROLE matreshka_app WITH PASSWORD 'ВАШ_СЛУЧАЙНЫЙ_ПАРОЛЬ_НЕ_МЕНЕЕ_32_СИМВОЛОВ';
```

4. В https://vercel.com/dashboard откройте проект **matreshka-v2** → Settings → Environment Variables и добавьте **зашифрованную** переменную `DATABASE_URL`:

```text
postgresql://matreshka_app.odaitemhtecieklsbnpd:ВАШ_ПАРОЛЬ@aws-0-eu-north-1.pooler.supabase.com:5432/postgres?sslmode=require
```

Используется **Session pooler**, совместимый с клиентом Node.js `pg` и серверными транзакциями. Если вместо латинских букв/цифр пароль содержит символы `@:/?#%`, их необходимо URL-кодировать. Пароль пользователя PostgreSQL никогда нельзя помещать в клиентский JavaScript.
5. После сохранения переменной нужен новый деплой из ветки `matreshka-v2`. Пока действует лимит деплоев Vercel, дождитесь сброса лимита или проверьте условия тарифа.

## Проверка после подключения

- `GET /api/config` → `databaseReady:true`, `adminConfigured:true`, `acceptingOrders:false`
- Админ-панель открывает формы добавления/изменения товаров, а не режим просмотра.
- `GET /api/products?limit=24&page=1` → 43 товара в базе, постраничный вывод.
- `POST /api/admin/login` → вход по переменной `ADMIN_PASSWORD`.
- Админ-авторизация блокирует IP после трёх ошибок на 1, 3, 9 минут и далее.

## Важное ограничение для покупателей в России

Данные сейчас находятся в регионе **Стокгольм, Швеция**. Перед сбором персональных данных покупателей из России необходимо проверить применимые требования к локализации данных и настроить подходящее российское хранение, если оно обязательно. До проверки держите `SHOP_OPEN=0` и `DATA_LOCALIZATION_REVIEWED=0`; серверная часть уже блокирует приём заказов и регистрацию покупателей при отключённой локализации.

Никаких настроек оригинального сайта `matreshkachita.vercel.app` менять не требуется.
