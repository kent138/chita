## Как это работает

`POSTGRES_URL` автоматически появляется в серверном окружении Vercel после установки официальной интеграции. Никаких паролей PostgreSQL в чат, GitHub или клиентский код помещать **не нужно**. Не создавайте заново `DATABASE_URL` вручную, если `POSTGRES_URL` уже подключён.

Все SQL-запросы магазина в управляемом режиме явно ссылаются на `matreshka_private`; использовать `public` для таблиц с данными покупателей не требуется. Сервер также проверяет наличие закрытой схемы и соответствие `SUPABASE_URL` идентификатору существующего проекта — при ошибочном подключении не начинает запись.
