# Бесплатная серверная регистрация «Матрёшки» — SpaceWeb

**Цель:** настоящие покупательские аккаунты, доступные с любого телефона и компьютера. Цена хостинга: 0 ₽ в рамках условий бесплатного тарифа; банковская карта для подключения бесплатного тарифа не требуется. SMS-подтверждение владельца хостинга всё же необходимо. Регистрация реальных покупателей остаётся выключенной, пока не подтверждены HTTPS, местонахождение данных и правовая готовность.

## Почему этот вариант

У SpaceWeb есть бессрочный тариф «Бесплатный» с PHP, одной MySQL и техническим доменом. [Официальные условия](https://help.sweb.ru/harakteristiki-tarifa-besplatnyj_1475.html). Для активации требуется подтверждение телефона. Бесплатный HTTPS/Let's Encrypt возможен после заполнения данных владельца и настройки сертификата. Ресурсы и нагрузка ограничены — это решение для малого старта, без гарантий полноценного коммерческого SLA.

## Что делает владелец аккаунта (без передачи секретов разработчику)

1. Зарегистрироваться на **[SpaceWeb Free](https://sweb.ru/hosting/free/)**, выбрать именно тариф **Бесплатный**, подтвердить номер телефона. Не выбирать тариф с 14-/30-дневным испытательным сроком и не заказывать платный домен.
2. В панели SpaceWeb открыть **MySQL / Базы данных**, создать одну базу и пользователя. Сохранить логин, имя базы и пароль **в личном менеджере паролей**. Пароль не отправлять в переписку.
3. Открыть **phpMyAdmin**, выбрать только что созданную MySQL и импортировать файл [schema-mysql57.sql](schema-mysql57.sql).
4. В личном файловом менеджере SpaceWeb **за пределами** сайта/папки `public_html` создать файл `matreshka-auth-config.php` на основе [config.example.php](config.example.php). Указать актуальные учётные данные MySQL и секретный ключ из **64 случайных шестнадцатеричных символов**. Заменить только переменные, не публиковать секреты в GitHub.
5. В корневую папку технического сайта `public_html` загрузить `public_html/api.php` и `public_html/.htaccess`. Установить PHP **8.2 или 8.3**.
6. В панели подтвердить реквизиты владельца и подключить Let's Encrypt на технический адрес `LOGIN.temp.swtest.ru`. **Проверить именно HTTPS**, без ошибок сертификата; техническая документация хостера должна подтверждать поддержку сертификата на выбранном бесплатном домене.
7. Проверить `https://LOGIN.temp.swtest.ru/api.php?action=health`. Успех: `{"ok":true}`. Если HTTPS не поддерживается бесплатным доменом, **не вводить пароли покупателей** и не включать регистрацию.
8. Подтвердить у хостера фактический регион хранения базы MySQL (Россия) и юридическую пригодность бесплатного тарифа для аккаунтов магазина; проверить политику персональных данных и при необходимости уведомления оператора. Нахождение компании в РФ само по себе не доказывает место хранения базы.
9. В Vercel для проекта **`matreshka-v2`** добавить Production переменные:
   - `RU_ACCOUNT_API_URL=https://LOGIN.temp.swtest.ru/api.php`
   - `ACCOUNT_DATA_LOCATION_CONFIRMED=RU` — только после проверки региона и обработки
   - `ACCOUNT_PRIVACY_POLICY_APPROVED=1` — только после проверки политики
   - `ACCOUNT_REGISTRATION_ENABLED=1` — разрешить регистрации
10. Развернуть ветку `matreshka-v2` в отдельном проекте Vercel. Не изменять `master` и старый магазин. Проверить `GET /api/config`: `cloudAccountsEnabled:true`, `cloudAccountApiBase` — HTTPS-адрес российского API. В настоящем браузере зарегистрировать тестовый аккаунт и с другого устройства войти под тем же логином и паролем, проверить сохранение двух лайков и корзины.

**Важно о безопасности:** ввод пароля происходит в браузере через прямое HTTPS-соединение с российским PHP-хостингом; Vercel не проксирует пароль или токен. В серверной базе хранятся только bcrypt-хеши паролей, логины, идентификаторы товаров, количества и SHA-256 хеши случайных токенов сессий. Токен сессии сохраняется в `sessionStorage` вкладки браузера. При открытии нового устройства требуется вход. Не используйте реальные ФИО, телефон или email в качестве логина. Для восстановления забытого пароля пока нет отдельного механизма.

## Дальнейшие действия

Зарегистрировать бесплатный хостинг может только владелец, поскольку нужны его телефон/SMS и согласие с условиями. После получения технического домена **можно сообщить только адрес домена без паролей**; затем можно совместно проверить HTTPS, API, подключение и публикацию.

Код API: [public_html/api.php](public_html/api.php). Миграция: [schema-mysql57.sql](schema-mysql57.sql). Тест: [GitHub Actions workflow](../../.github/workflows/free-russian-auth.yml).

### Ограничения

- Нет платёжного шлюза и восстановления пароля.
- Бесплатный тариф может ограничить ресурсы или заблокировать аккаунт из-за нагрузки; сохраняйте резервные копии MySQL.
- Бесплатный хостинг не означает автоматического соответствия требованиям о персональных данных. Для коммерческого запуска требуется отдельная проверка.
- Не выключайте `SHOP_OPEN=0` до готовности оформления заказа и оплаты.
